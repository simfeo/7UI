## Full description (max 4000, now 556)
7UI 是一款专为喜欢手机界面整洁、操作流畅的用户设计的首页启动器。向上滑动即可查看应用，左右滑动可在页面间切换，长按任意位置即可执行快速操作。

主屏幕
• 页面数量不限，配有底栏和可选搜索栏
• 五种颜色的文件夹
• 可拖动和调整大小的小工具
• 编辑模式（双指捏合或长按空白处）：添加、删除和重新排序页面，并选择默认页面
• 可选页面循环功能

应用屏幕
• 采用分页网格而非无尽列表，按您喜欢的方式排列
• 可选择 4x5、5x5 或 5x6 网格
• 实时搜索，并通过页面指示器快速跳转页面

自然流畅的手势操作
• 应用屏幕会跟随您的手指移动，并根据滑动速度自动定位
• 每次滑动仅沿一个方向移动，因此页面绝不会意外翻转

快速选项
• 长按图标可访问应用快捷方式、应用信息、移除和卸载
• “添加到主屏幕”会询问该应用应放置在哪个页面

侧边栏
• 屏幕边缘的纤细拉手可随时从任何位置打开您最常用的应用
• 左侧或右侧均可设置，横屏模式下自动隐藏

备份与恢复
• 将布局和设置保存为文件，随时恢复

设计即隐私
• 无网络访问、无广告、无追踪。您的布局绝不会离开手机。

支持英语、德语、西班牙语、法语、意大利语、日语、韩语、葡萄牙语、乌克兰语和中文。

7UI 可免费用于个人及其他非商业用途。
