## Full description (max 4000, now 835)
7UIは、スマホの画面をすっきり整え、素早く操作したい人向けのホーム画面ランチャーです。上にスワイプしてアプリを表示し、横にスワイプしてページを切り替え、どこかを長押しするとクイックアクションが実行できます。

ホーム画面
• ページ数は無制限。ドックとオプションの検索バーを搭載
• 5色のフォルダ
• 移動やサイズ変更が可能なウィジェット
• 編集モード（空いている場所をピンチまたは長押し）：ページの追加・削除・並べ替え、およびデフォルトページの選択が可能
• オプションでページをループ表示

アプリ画面
• 無限リストではなくページ分けされたグリッドで、お好みの配置が可能
• 4×5、5×5、5×6のグリッドから選択可能
• ライブ検索と、ページインジケーターを使った素早いページ移動

直感的なジェスチャー
• アプリ画面は指の動きに追従し、スワイプの速度に合わせて位置が決まります
• スワイプは一方向のみに移動するため、誤ってページが切り替わることはありません

クイックオプション
• アイコンを長押しすると、アプリのショートカット、アプリ情報、削除、アンインストールが表示されます
• 「ホーム画面に追加」を選択すると、アプリをどのページに配置するか尋ねられます

サイドパネル
• 画面端にある細いハンドルをスワイプすると、どこからでもお気に入りのアプリを起動できます
• 左側または右側に配置可能。横向き表示時は非表示になります

バックアップと復元
• レイアウトと設定をファイルに保存し、いつでも復元できます

プライバシーを重視した設計
• インターネット接続なし、広告なし、追跡なし。レイアウトデータが端末外に出ることはありません。
