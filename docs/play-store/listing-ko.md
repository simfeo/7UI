7UI Launcher

## Short description (max 80, now 43)
페이지, 폴더, 위젯 및 사이드 패널이 포함된 깔끔하고 제스처 기반의 홈 화면

## Full description (max 4000, now 909)
7UI는 휴대폰 화면을 깔끔하게 정리하고 빠르게 이동하고 싶어 하는 분들을 위한 홈 화면 런처입니다. 위로 스와이프하면 앱이 표시되고, 옆으로 스와이프하면 페이지를 넘길 수 있으며, 어떤 항목이든 길게 누르면 빠른 동작을 실행할 수 있습니다.

홈 화면
• 도크와 선택적 검색 창이 포함된, 원하는 만큼의 페이지를 생성할 수 있습니다.
• 5가지 색상의 폴더
• 위치 이동 및 크기 조정이 가능한 위젯
• 편집 모드(빈 공간을 핀치하거나 길게 누르기): 페이지 추가, 삭제, 순서 변경 및 기본 페이지 선택
• 선택적 페이지 순환 기능

앱 화면
• 끝없는 목록 대신 페이지별 그리드 방식으로, 원하는 대로 배열 가능
• 4x5, 5x5 또는 5x6 그리드 선택 가능
• 실시간 검색 및 페이지 표시기를 통한 빠른 페이지 이동

직관적인 제스처
• 앱 화면은 손가락의 움직임을 따라가며, 스와이프 속도에 맞춰 정렬됩니다
• 각 스와이프는 한 방향으로만 이동하므로, 페이지가 실수로 뒤집히는 일이 없습니다

빠른 옵션
• 아이콘을 길게 누르면 앱 바로가기, 앱 정보, 제거 및 삭제 메뉴가 표시됩니다
• ‘홈 화면에 추가’를 선택하면 앱을 배치할 페이지를 묻습니다

사이드 패널
• 화면 가장자리에 있는 얇은 핸들을 통해 어디서든 즐겨 찾는 앱을 실행할 수 있습니다
• 왼쪽 또는 오른쪽에 위치하며, 가로 모드에서는 숨겨집니다

백업 및 복원
• 레이아웃과 설정을 파일로 저장하여 언제든지 복원할 수 있습니다

기본적으로 사생활 보호
• 인터넷 접속 없음, 광고 없음, 추적 없음. 레이아웃 정보는 휴대폰 밖으로 절대 유출되지 않습니다.

영어, 독일어, 스페인어, 프랑스어, 이탈리아어, 일본어, 한국어, 포르투갈어, 우크라이나어, 중국어로 제공됩니다.

7UI는 개인용 및 기타 비상업적 용도로 무료로 사용할 수 있습니다.
